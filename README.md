# project-with-multiple-prs

A small Node.js project (no dependencies) used to demonstrate a multi-PR workflow.

## Usage

```bash
npm start   # run the app
npm test    # run tests with the built-in node:test runner
```

## Planned PRs

1. `feature/math-utils` – math helper functions + tests
2. `feature/string-utils` – string helper functions + tests
3. `feature/http-server` – tiny HTTP server with a `/health` endpoint
